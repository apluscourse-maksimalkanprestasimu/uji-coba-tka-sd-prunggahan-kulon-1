# Uji Coba TKA 2027 — UPT SD Negeri Prunggahan Kulon 1

Aplikasi latihan berbasis web untuk uji coba TKA. Source awal disimpan pada `source/uji_coba_tka_sd_negeri_prunggahan_kulon_1.zip` dan akan diekstrak oleh workflow GitHub Pages.

## Status
- Aplikasi awal berupa HTML statis.
- Belum terhubung ke database online. Nilai dan identitas peserta belum tersimpan terpusat.
- Jangan gunakan NISN atau data pribadi peserta pada website publik sebelum kebijakan privasi, keamanan akses, dan penyimpanan data disiapkan.
- Token ujian pada HTML awal tertanam di sisi klien sehingga bukan mekanisme keamanan yang rahasia.

## Publikasi
Workflow `.github/workflows/pages.yml` akan menerbitkan HTML melalui GitHub Pages setelah Pages diatur menggunakan **GitHub Actions** pada Settings → Pages.
